# 将 AI 提示音采纳到用户声音包，独立选择使用作用域

## 决策

生成与采纳面向普通**用户声音包**，目标为显式 `packID + Event`。界面称呼「提示音组」
不引入另一类包、数据库或声音映射。Global 与 Surface 仍按 [ADR 0005](0005-use-global-sound-defaults-with-sparse-surface-overrides.md)
选择完整包；缺失的 Surface 覆盖逐字段继承 Global，损坏的显式覆盖 fail closed。生成入口在
「声音」目的页，服务/profile 与各自凭据状态在包列表之外展示。已生成且仍有效的候选的采纳只受
候选身份、包和事件校验约束；G3 凭据门只限制**新的联网生成**，凭据后来消失不撤销候选采纳资格。

三条进入路径：

1. 已安装、可编辑、健康的用户包可以直接采纳。修改包级映射立即影响所有有效选择该包的
   Global 与 Surface，包括继承 Global 的来源。界面在动作前列出使用者，不要求确认弹窗。
2. 新建空「提示音组」先保持未发布草稿。取消或关闭时丢弃空草稿；首个音频经完整导入与绑定
   **成功后**才原子发布为普通用户包，自动命名并允许改名。失败不得留下可被选用的空包或声称发布。
3. 可复制任意已安装的健康包，包括用户包与只读内置包。复制完整成功即发布、选中并查看可编辑
   副本；普通「复制」不改变任何 Global/Surface 选包。只读内置包的缺声深链应明确标注目标，
   提供「复制并用于此来源」或「复制并用于全局默认」：复制成功后即对所指目标应用，应用失败
   时保留可找回的副本并报告未应用，不得显示成功或悄悄应用到别的作用域。之后的 AI 生成仍由
   用户显式触发。

采纳前重新验证目标包仍已安装、可编辑、健康且身份未漂移，`Event` 是现有公共事件，候选属于
当前 generation/profile/route 的已验证集合且身份唯一有效。包锁、安全导入、manifest bind 和
刷新仍是完整事务；失败保留旧绑定并如实展示可能的部分磁盘结果。选择作用域不是采纳资格条件，
不再要求独占包。配置损坏会使「谁在使用」的统计不完整，应标明范围不完整；它不能禁止向其他
健康用户包采纳，也不能把损坏覆盖默默当成继承。

复制副本时，以及向带整包声明的用户包采纳 AI 音频时，修改后的包不再保留整包 `license` 与
`author` 声明；保留其他未知 manifest 字段、原始包、独立 attribution 文件与第三方许可材料。
动作旁提前说明这一结果，不增加确认弹窗。若元数据移除或安全写入失败，动作整体不得声称成功。

包侧栏覆盖度固定以公共 `Event.allCases` 显示 `n/5`。「声音」页的事件名称是普通标签，进入页面
不默认选中事件；点击「描述生成」或从「事件与提示音」的缺声入口进入时，才定位对应事件并在行下方
显示生成表单或只读包复制引导。生成时保留目标包与事件、服务和凭据状态，以及采纳后受影响的
有效使用者。宿主事件能力仍由现有 `HostCapabilityBinding` 持有，在「事件与提示音」按当前来源
查看；来源支持、当前实现和当前激活是不同事实。不支持或未实现的事件不提供缺声生成入口，
但任何宿主覆盖率都不限制「声音」中的包级生成。服务选择只能使用已注册的固定 profile；
`routes.keys` 与 route-owned 候选集合政策继续由 ADR 0006、0011、0014–0015 约束。

## 取代与实施边界

本 ADR 取代 ADR 0007 的 Surface 独占门、Global 禁用、`sharedPack` 证明和
`HostSurfaceID + Event + packID` 采用目标。它不改变 ADR 0005 的声音解析，也不放宽 Provider、
凭据、临时候选与音频安全合同。**accepted 是设计决定**；当前 Swift 生产代码的迁移、自动测试、
原生交互验收、真实生成与发布均须分别记录，不能因本文档或 HTML 原型而视为完成。
