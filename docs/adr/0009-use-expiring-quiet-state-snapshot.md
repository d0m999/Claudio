# 使用带有效期的动态静默快照跨进程抑制自动提示音

专注模式与日历忙碌属于瞬时系统事实，由常驻 GUI 在用户分别授权后观察，并原子发布一份带 schema、生成时间、过期时间和静默原因的最小快照；短生命周期的 hook/helper 进程只读取这份快照来决定是否抑制自动提示音。动态静默不改写事件开关、Surface 覆盖、声音包或主音量，手工试听也不受它影响。快照缺失、损坏、代次倒退或过期时忽略动态静默并留下可诊断结果，不能让一次陈旧的专注状态永久静音。

直接改写现有配置会丢失用户原来的逐事件选择或音量，而让每个 hook 进程自行查询 Focus 与 Calendar 又会重复请求隐私权限、增加同步回调延迟并产生不一致状态。带有效期的快照保留了 GUI 作为系统权限 owner、helper 作为播放执行者的边界；代价是设置页必须如实显示授权、观察和快照健康状态，并明确动态抑制是 best-effort 的实时策略而不是历史事实。
