# 声音包库以 100 个已安装包为设计容量

claudi0 的声音包读取架构以单台机器最多 100 个已安装声音包为性能设计边界：在该范围内承诺交互性能，超过 100 个仍保证数据正确性，但暂不承诺延迟或引入千级库所需的分页架构。以 Apple Silicon M1、APFS、本地磁盘和 Release 构建为基准，100 个包的首次无缓存读取从发起到完整声音包库可交互必须达到 `p95 ≤ 500 ms`；已有会话快照时，从打开入口到旧快照可交互必须达到 `p95 ≤ 100 ms`。窗口外壳和加载态不得等待读取完成，声音包扫描不得在 `MainActor` 执行文件 I/O。这个选择在当前少量内置包与未来社区声音包之间留出增长空间，同时避免按尚不存在的 marketplace 规模过度设计。
