## 当前阻断

`bash scripts/dev-bundle.sh` 在当前 HEAD 的 arm64 GUI 体积门禁失败：`claudi0-app` 为 **6,059,208 B**，预算 **6,000,000 B**，超出 **59,208 B**。脚本中途留下的 `dist/claudi0.app` 不完整且签名校验失败；走查后已删除，避免误用。尝试读取该菜单栏进程的原生窗口得到 `timeoutReached`；以上界面观察均来自另行签名的临时 DEBUG 窗口探针，探针及 worktree 已在走查后清理。

后续核对：仅为继续检查原生界面，以 `CLAUDIO_GUI_BYTES_PER_ARCH=6100000 bash scripts/dev-bundle.sh` 生成了当前源码的单架构检查包；打包脚本与独立 `codesign --verify --deep --strict` 均确认签名有效。此覆盖没有更改仓库的 6,000,000 B 门槛；对已签名包重新执行标准 `bash scripts/check-release-size.sh dist/claudi0.app` 仍失败（6,042,112 B > 6,000,000 B），标准打包在签名前测得 6,059,208 B。真实菜单栏进程可以启动，但原生桌面工具按 app 路径和 `SystemUIServer` 读取窗口仍返回 `timeoutReached`；已停止本次启动的进程。当前 `dist/claudi0.app` 是有效的临时检查包，未纳入 Git。
