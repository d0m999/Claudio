# WorkBuddy icon provenance

`workbuddy.png` is copied byte-for-byte from the installed WorkBuddy Desktop bundle:

```text
/Applications/WorkBuddy.app/Contents/Resources/app.asar.unpacked/resources/icon.png
```

Observed installation:

- App: `WorkBuddy`
- Version: `5.3.14`
- Bundle ID: `com.workbuddy.workbuddy`
- Image: `1024×1024` RGBA PNG with alpha
- Code-signing authority: `Developer ID Application: Tencent Technology (Shanghai) Company Limited`

The official WorkBuddy site identifies the product as Tencent WorkBuddy and publishes the macOS installation guide at:

- <https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Mac-Guide>
- <https://www.workbuddy.ai/document/term>

The local signed app bundle is the source of truth for the icon used by the installed version. This asset is prepared for local prototype/Figma import; it does not grant trademark or redistribution rights.
